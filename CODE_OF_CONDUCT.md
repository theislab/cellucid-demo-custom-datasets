# Code of conduct

We want participation to be safe, respectful, and constructive.

Be considerate, welcome people with different technical and scientific
backgrounds, discuss evidence rather than people, and respect privacy and data
governance. Harassment, discrimination, intimidation, publication of private
information, and hostile conduct are not accepted.

Repository maintainers may remove content or participation that violates these
expectations. Report conduct concerns privately to the maintainers of the
GitHub repository.
