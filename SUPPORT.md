# Support

For this example repository, open an issue with:

- the exact dataset ID;
- the URL or loading mode used;
- browser, operating system, and Cellucid version;
- expected and observed behavior;
- console or server errors with secrets removed.

Use the ecosystem issue tracker that owns the behavior:

- web viewer and rendering: <https://github.com/theislab/cellucid/issues>
- Python package, CLI, server, Jupyter, and documentation:
  <https://github.com/theislab/cellucid-python/issues>
- R exporter: <https://github.com/theislab/cellucid-r/issues>
- public sample catalog: <https://github.com/theislab/cellucid-datasets/issues>
- community annotation template:
  <https://github.com/theislab/cellucid-annotation/issues>
