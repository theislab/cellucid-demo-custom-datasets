# Security and privacy

These examples are fully synthetic and contain no human-subject or patient
data. Treat every custom export as public before enabling GitHub Pages: Pages
content is delivered to anyone who can reach the URL, and browser requests can
appear in host access logs.

Do not commit:

- names, contact details, clinical dates, free text, geographic identifiers,
  sample keys that can be mapped back to a person, or rare identifying labels;
- access tokens, cookies, passwords, private server URLs, or signed URLs;
- private source paths, machine usernames, or internal infrastructure names;
- third-party data unless its license explicitly permits redistribution.

Before publication, review observation labels and category names as carefully
as expression values. Quantization and compression reduce bytes; they do not
anonymize a dataset.

For a vulnerability in this repository, use GitHub’s private vulnerability
reporting for this repository rather than a public issue. For a
Cellucid viewer or package vulnerability, report it in the owning Cellucid
repository.
